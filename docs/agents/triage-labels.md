# Triage Labels

The engineering skills use five canonical triage roles. Map each role to the GitHub label below.

| Canonical role    | Label in this tracker | Meaning                                      |
| ----------------- | --------------------- | -------------------------------------------- |
| `needs-triage`    | `needs-triage`        | Maintainer needs to evaluate this issue      |
| `needs-info`      | `needs-info`          | Waiting on the reporter for more information |
| `ready-for-agent` | `ready-for-agent`     | Fully specified, ready for an AFK agent      |
| `ready-for-human` | `ready-for-human`     | Requires human implementation                |
| `wontfix`         | `wontfix`             | Will not be actioned                         |

When a skill mentions a triage role, use the corresponding label string in this table.

To change the vocabulary, edit the "Label in this tracker" column.
